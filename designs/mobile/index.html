手机上的四种读法

同样是这篇文章、同一批生词、同一套交互（点词查义 / 看图译文），只换“手机怎么翻”。 在电脑上打开会显示成 390×844 的手机框；在手机上打开就是全屏。

1 · 沉浸式已落地

Immersive

没有工具栏、没有底栏、没有进度条。控件收进底部一颗胶囊，滚动时自动淡出。查词从下方升半屏抽屉。

代价：入口都得摸一次才知道，新手需要一层提示。

2 · 逐段翻页已落地

One paragraph per page

一段一屏，上滑恰好停在下一段（scroll-snap）。顶部 8 格进度，底部大号上一段/译文/下一段。

代价：看不到上下文，回查要往回翻。
打开 →

3 · 大字已落地

Big type · night

20px 字号、行高 1.95，三个 56px 大键全在拇指区。查词就地展开小卡，不盖住下半屏。

代价：一屏信息少，长文翻得久。
打开 →

4 · 原生 App未采用

Native shell

顶栏 + 分段控件（原文/对照/译文）+ 卡片流 + 底部四个 Tab。最保守，也最不需要学习。

代价：最不沉浸，chrome 占了上下各一条。
打开 →
如果是安卓，我会这样组合：
  1. 日常用 1（沉浸式）——手机阅读最怕上下两条栏，它一件都没有；胶囊在拇指区，单手够得着。
  2. 躺着用 3（大字夜读）——和 1 共用一套内容，只换字号/间距/主题，做成“夜读模式”而不是第四套 UI。
  3. 2（逐段翻页）做成可选：地铁上信号差、注意力碎的时候打开，一段一屏确实更容易“推”下去。
  4. 4（原生 App）不建议做，除非你打算把精读/生词/复习做成三个独立日常入口——那是另一种产品形态。
四个都是单文件、无外部依赖；桌面打开显示为手机框，手机上打开全屏。
